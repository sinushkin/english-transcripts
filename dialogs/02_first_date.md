# Dialog 2: First Date

**Level:** B1  
**Duration:** 3-4 min  
**Key idioms:** 4

## Characters
- **Alex:** University student
- **Jordan:** Alex's date

## Full Dialogue

**Alex:** I'm so nervous! This is the first time I've done something like this.

**Jordan:** It seems to me you're overthinking it. Just be yourself! I already like you.

**Alex:** Really? I feel like I'm wiped out from work today, but I'm happy to be here.

**Jordan:** Let's hang out and have fun! No pressure. Want to grab dinner?

**Alex:** Sure! And hey, you look amazing tonight. I'm all set for an amazing evening with you!

**Jordan:** You're making me blush! Let's break a leg on this date together!
