# english-transcripts

Главный репозиторий для анализа и расшифровки английских видео-уроков с YouTube.

## Структура

```
english-transcripts/
├── CLAUDE.md                      # этот файл (инструкции)
├── README.md                      # публичное описание проекта
├── download_playlist_subs.py      # скрипт для загрузки плейлистов
├── dragon-club-phrases.csv        # таблица всех видео плейлиста (429)
└── transcript/                    # анализированные видео (227 видео, 1100+ фраз)
    ├── FOzoCpD27Cs.md            # 5 фраз (pass by, get over, fall short...)
    ├── 2oScAyV9p0A.md            # 5 фраз с TAKE
    ├── BohT_bO9OWY.md            # 7 фраз с GET
    ├── KNzLKiZlJnU.md            # 20 фраз с RUN
    ├── VKrpSyNVcuo.md            # AFFECT vs EFFECT
    ├── zvhGaeZ7YbQ.md            # завершающее видео
    └── ... (227 видео всего, A-Z покрытие)

Примечание: русские субтитры в виде .ru.srt хранятся отдельно в ~/data/dragon-club/
```

## Плейлист

- **Видео:** 429 всего, **296 с русскими субтитрами** (69%)

- **Тема:** Английские фразы для разговорной речи

## Скачивание плейлиста

```bash
python3 download_playlist_subs.py \
  "https://www.youtube.com/playlist?list=PL4BHdEpMZRTiNQ6ZYDmhguuHwbRNSYsZM" \
  dragon-club-phrases.csv
```

**Особенности:**
- Первый запуск: загружает плейлист (429 видео), сохраняет URL+названия в CSV, затем скачивает
- Следующие запуски: просто читает CSV, пропускает уже скаченные, продолжает с того же места
- CSV обновляется после каждого видео (можно убить процесс и продолжить)
- Видео БЕЗ русских субтитров пропускаются (YouTube их не предоставляет)

## Анализ видео в транскрипты

**Важно:** Качество автоматических субтитров YouTube низкое (много ошибок распознавания). Субтитры используются только как **ориентир**. **Основной анализ возлагается на интеллект Claude** — восстановление правильного смысла, грамматический анализ, примеры, контекст.

**Формат `.md` файла:**
- Каждая фраза = отдельный раздел (## N. Фраза)
- Подразделы: 
  - "Как говорят в реальной жизни" (EN) — восстановленный правильный пример
  - "Русский аналог" — перевод на русский
  - "Объяснение" — смысл и использование
  - "Грамматика" — структура и формы
  - "Примеры в контексте" — реальные примеры использования
  - "Когда использовать" — контекст применения
- Файл: `transcript/<VIDEO_ID>.md`

**Пример:** `transcript/FOzoCpD27Cs.md`
- 5 фраз: pass by, get over, fall short, slip one's mind, hold back
- Каждая с правильными примерами, подробной грамматикой, практическим контекстом
- Синонимы, альтернативные выражения, грамматические примечания
- Советы для практики и применения

## Соглашения

- Имена файлов = ID видео (то что после `v=`)
- Суффиксы: `.ru.srt` (субтитры), `.md` (анализ)
- CSV: `dragon-club-phrases.csv` содержит `url | title | subtitle_file`

## Инструменты

**yt-dlp** (2026.10.26):
```bash
# Скачать субтитры видео
yt-dlp --skip-download --write-auto-subs --sub-langs "ru" --convert-subs srt \
  -o "%(id)s" --extractor-args "youtube:player_client=web,mweb,android" \
  "https://www.youtube.com/watch?v=<ID>"
```

**Python скрипт** `download_playlist_subs.py`:
- Использует pandas для работы с CSV
- Автоматически продолжает загрузку
- Обрабатывает ошибки (видео без субтитров, сетевые ошибки)

## Заметки

- Учитель говорит и по-русски и по-английски → субтитры RU достаточно, EN не нужны
- YouTube может блокировать много запросов (Error 429) — дать время между запросами
- Если нужна чистая текст без таймкодов — использовать sed/awk для парсинга `.srt`
