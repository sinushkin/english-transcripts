# 7 фразовых глаголов с GO

**Видео:** https://www.youtube.com/watch?v=8lpAyq_yoyM  
**ID:** 8lpAyq_yoyM  
**Тема:** Фразовые глаголы: go off, go on, go down, go up, go ahead, go without, go by

> Фразы восстановлены по русским репликам учителя: автосубтитры YouTube искажают английскую речь. Таймкод ▶ — начало объяснения фразы.

## 1. go off — портиться (о еде)  [▶ 0:12](https://youtu.be/8lpAyq_yoyM?t=12)

- **EN:** When I got back from vacation, the house smelled terrible: the fridge had broken and the food had gone off.
- **RU:** Вернувшись из отпуска, я обнаружил, что в доме воняет: холодильник сломался и продукты испортились.
- **Объяснение:** Off показывает, что вещь вышла из хорошего состояния. Had broken / had gone off — Past Perfect, действие раньше.

## 2. go on — продолжаться  [▶ 1:33](https://youtu.be/8lpAyq_yoyM?t=93)

- **EN:** The movie has been going on for three hours.
- **RU:** Фильм продолжается уже три часа.
- **Объяснение:** Present Perfect Continuous, потому что действие длится до сих пор.

## 3. go down — проигрывать, быть побеждённым  [▶ 2:29](https://youtu.be/8lpAyq_yoyM?t=149)

- **EN:** The challenger is landing quick punches. It looks like the champion is going down.
- **RU:** Претендент наносит быстрые удары. Похоже, чемпион проигрывает.
- **Объяснение:** Down — неблагоприятное состояние. Punch — удар рукой, kick — ногой.

## 4. go up — расти (о цене)  [▶ 4:33](https://youtu.be/8lpAyq_yoyM?t=273)

- **EN:** The price of Bitcoin is finally going up. I think I'll sell in a month.
- **RU:** Цена биткойна наконец растёт. Думаю, через месяц продам.
- **Объяснение:** Up — позитивное изменение, down — негативное. Через месяц — in a month.

## 5. go ahead — продолжаться, идти вперёд  [▶ 5:50](https://youtu.be/8lpAyq_yoyM?t=350)

- **EN:** The project is still going ahead, with or without him.
- **RU:** Проект всё ещё продолжается, с ним или без него.
- **Объяснение:** Учитель говорит, что у «продолжать» есть и другие варианты (go on и др.).

## 6. go without — обходиться без  [▶ 7:38](https://youtu.be/8lpAyq_yoyM?t=458)

- **EN:** I want to try to go without sugar for a month, though I'm not sure I can do it.
- **RU:** Хочу попробовать обходиться без сахара месяц, хотя не уверен, что получится.
- **Объяснение:** Though можно ставить в конце предложения.

## 7. go by (?) — пройти мимо  [▶ 8:55](https://youtu.be/8lpAyq_yoyM?t=535)

- **EN:** The café owner set such prices that no one can go by without stopping.
- **RU:** Хозяин кафе установил такие цены, что никто не может пройти мимо.
- **Объяснение:** Английское слово в автосубтитрах искажено; учитель говорит, что эту фразу «надо просто знать». Set prices — устанавливать цены.
