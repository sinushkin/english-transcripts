# 20 фраз и идиом с глаголом run

**Видео:** https://www.youtube.com/watch?v=LElnUk2PZSc  
**ID:** LElnUk2PZSc  
**Тема:** Run в значениях «управлять», «баллотироваться», «опаздывать», «кончаться» и других идиомах

> Фразы восстановлены по русским репликам учителя: автосубтитры YouTube искажают английскую речь. Таймкод ▶ — начало объяснения фразы.

В заголовке видео заявлено 20 фраз, в субтитрах разобрано 19: одна фраза потерялась в неразборчивых местах. Рекламные вставки с 2:55 по 3:59 и с 7:29 по 8:27 пропущены.

## 1. run a business — управлять бизнесом  [▶ 0:15](https://youtu.be/LElnUk2PZSc?t=15)

- **EN:** She has been running her own bakery for more than five years.
- **RU:** Уже более пяти лет она управляет собственной пекарней.
- **Объяснение:** Вместо business можно назвать тип деятельности (bakery — пекарня), значение run — управлять не меняется. Present Perfect Continuous: has been running.

## 2. dry run — прогон, репетиция, пробный запуск  [▶ 0:49](https://youtu.be/LElnUk2PZSc?t=49)

- **EN:** I think we should do a few dry runs before we give the presentation.
- **RU:** Я думаю, нам следует провести несколько пробных прогонов, прежде чем мы проведём презентацию.
- **Объяснение:** Dry дословно «сухой»; dry run — просто тренировка, репетиция чего-либо.

## 3. run for office — баллотироваться (на выборах)  [▶ 1:28](https://youtu.be/LElnUk2PZSc?t=88)

- **EN:** He decided to run for mayor in the upcoming election.
- **RU:** Он решил баллотироваться на пост мэра на предстоящих выборах.
- **Объяснение:** Run for office без уточнения означает пост президента; вместо office можно назвать другую должность: run for mayor. Upcoming — предстоящий.

## 4. in the long run — в долгосрочной перспективе  [▶ 2:04](https://youtu.be/LElnUk2PZSc?t=124)

- **EN:** Many people find that in the long run they really want to have children.
- **RU:** Многие люди обнаруживают, что в долгосрочной перспективе они действительно хотят иметь детей.
- **Объяснение:** Супер популярная фраза: in the long run — в конечном счёте, в будущем.

## 5. run errands — выполнять поручения, бегать по делам  [▶ 2:26](https://youtu.be/LElnUk2PZSc?t=146)

- **EN:** I need to run a few errands before going home.
- **RU:** Мне нужно выполнить несколько поручений, прежде чем вернуться домой.
- **Объяснение:** Errand — поручение, мелкое дело. Можно во множественном числе (run errands) или с a few. Реклама уроков (с 2:55 до 3:59) пропущена.

## 6. make a run for it (?) — пытаться убежать, броситься бежать  [▶ 4:01](https://youtu.be/LElnUk2PZSc?t=241)

- **EN:** It's raining. Let's make a run for it and get to the car.
- **RU:** Идёт дождь. Давайте побежим и доберёмся до машины.
- **Объяснение:** Начало фразы в субтитрах потеряно; по значению «пытаться убежать от чего-то, побежать и дойти куда-то» это make a run for it (?). Английское предложение восстановлено по смыслу.

## 7. make my blood run cold (?) — кровь стынет в жилах, становится не по себе  [▶ 4:39](https://youtu.be/LElnUk2PZSc?t=279)

- **EN:** The sight of her makes my blood run cold. I wish she would go away.
- **RU:** При виде её у меня кровь стынет в жилах. Хотел бы я, чтобы она ушла.
- **Объяснение:** Фраза в субтитрах искажена; значение — используем, когда нам не комфортно, не по себе. Реконструкция (?).

## 8. hit the ground running (?) — быстро начать, начать на полную мощность  [▶ 5:01](https://youtu.be/LElnUk2PZSc?t=301)

- **EN:** If we do research, we will hit the ground running.
- **RU:** Если мы проведём исследование, мы начнём на полную мощность.
- **Объяснение:** В субтитрах слышно что-то вроде get off to running; точная формулировка не ясна (?). По значению «быстрое начало» это hit the ground running или get off to a running start. Носители часто используют такие фразы, чтобы точнее описать начало, а не просто start.

## 9. run around in circles — бегать по кругу, топтаться на месте  [▶ 5:38](https://youtu.be/LElnUk2PZSc?t=338)

- **EN:** It feels like we're just running around in circles.
- **RU:** Такое ощущение, что мы просто бегаем по кругу.
- **Объяснение:** Логичная фраза: переносное значение — много делать, но без результата. Идиомы делают речь интереснее.

## 10. run a fever / run a temperature — иметь жар, температуру  [▶ 6:12](https://youtu.be/LElnUk2PZSc?t=372)

- **EN:** I might be running a fever.
- **RU:** Возможно, у меня температура.
- **Объяснение:** Fever — лихорадка, жар, температура. Run здесь не имеет отношения к бегу. Если не уверены, добавляем might/maybe. Можно сказать и have a high temperature (про ребёнка — he has a temperature).

## 11. run a tight ship — держать всё под строгим контролем  [▶ 7:00](https://youtu.be/LElnUk2PZSc?t=420)

- **EN:** I like to run a tight ship, so get ready to work.
- **RU:** Я люблю держать всё под строгим контролем, так что готовьтесь к работе.
- **Объяснение:** Идиома: управлять строго, как капитан корабля, но дословно не используется. Реклама курса (с 7:29 до 8:27) пропущена.

## 12. run around like a chicken with its head cut off — бегать как курица с отрезанной головой, паниковать  [▶ 8:59](https://youtu.be/LElnUk2PZSc?t=539)

- **EN:** Stop running around like a chicken with its head cut off and tell me what happened.
- **RU:** Перестань бегать как курица с отрезанной головой и расскажи мне, что случилось.
- **Объяснение:** Популярная идиома, есть и в русском. Одним словом: перестань паниковать.

## 13. run late — опаздывать  [▶ 9:29](https://youtu.be/LElnUk2PZSc?t=569)

- **EN:** I'm running late for a meeting, so I'll be there in 10 minutes.
- **RU:** Я опаздываю на встречу, так что буду через 10 минут.
- **Объяснение:** Для процесса «опаздываю прямо сейчас» лучше использовать run late (Present Continuous), а be late тоже можно, но с прилагательным используется именно be.

## 14. run in the family — передаваться по наследству (в семье)  [▶ 10:05](https://youtu.be/LElnUk2PZSc?t=605)

- **EN:** Musical talent runs in my family. All the children are musical, like their parents.
- **RU:** Музыкальный талант присущ моей семье. Все дети музыкальные, как и родители.
- **Объяснение:** Передаётся по наследству талант, качество, внешние характеристики. Run in the family.

## 15. run into a brick wall — наткнуться на каменную стену (на непреодолимое препятствие)  [▶ 10:33](https://youtu.be/LElnUk2PZSc?t=633)

- **RU:** Мы наткнулись на каменную стену, когда пытались получить разрешение на строительство.
- **Объяснение:** Идиома, легко понять, потому что в русском то же самое. Permit — разрешение.

## 16. run out of — кончаться, израсходовать  [▶ 10:56](https://youtu.be/LElnUk2PZSc?t=656)

- **EN:** We're going to run out of gas soon. We'd better stop.
- **RU:** Скоро у нас кончится бензин. Нам лучше остановиться.
- **Объяснение:** Очень хороший фразовый глагол: что-то на грани того, чтобы закончиться. Не совсем дословно переводится, русскоязычным сложно. Структура run out of + что (gas, time, money).

## 17. run down / run over (?) — измотать, избивать кого-то (зависит от контекста)  [▶ 11:37](https://youtu.be/LElnUk2PZSc?t=697)

## 18. run up (a bill) — накопить долги, набрать счёт  [▶ 12:09](https://youtu.be/LElnUk2PZSc?t=729)

- **EN:** He ran up a huge bill on his Visa card buying clothes.

- **Объяснение:** Run up — навязать долги или счёт на себя. Разделяемый фразовый глагол: в прошедшем ran up, в середине можно поставить объект. Английский пример приблизительный (?): в субтитрах слышно «использовал свою кредитную карту Visa для покупки одежды».
